PROG 102 — JavaScript Site Demo

FILES
- index.html: the website content and navigation buttons
- style.css: colors, layout, typography, and responsive styling
- script.js: JavaScript that switches between the three sections

HOW TO VIEW
1. Keep all three files in the same folder.
2. Double-click index.html to open it in a web browser.
3. Click Home, About, and Projects. Each button should show a different section without loading a new page.

HOW TO SUBMIT ON GITHUB
1. Create a new GitHub repository for the assignment.
2. Upload index.html, style.css, and script.js (not just the folder).
3. In the repository, open Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select the main branch and /(root), then save.
6. Wait for GitHub Pages to publish, then open the provided website link.
7. Capture one screenshot each with Home, About, and Projects selected. Upload all three screenshots to the assignment submission.
